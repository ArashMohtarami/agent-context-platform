THE KNOWLEDGE LAYER

Conversations end.
Good decisions should stay.

Agents do the reasoning and implementation. The platform stores the facts, retrieves relevant context and preserves where it came from.

A clear path from client to context.

Compatible clients use a thin MCP server. Local Codex can connect over stdio; remote clients use Streamable HTTP. The gateway checks client identity, operation scopes and resource grants.

FastAPI services talk to MongoDB. MongoDB coordinates lexical and vector search through its private mongot service. A local embedding model supplies the vectors.

Understand the architecture ↗

API access binds to loopback by default. MongoDB and search ports stay on the internal container network.

BEFORE CHANGING CODE

Bring back the relevant decision.

Resolve the explicit project, then search its authorized context alongside reusable skills and memory. Hybrid retrieval ranks, deduplicates and budgets results.

Follow the daily workflow ↗
search_knowledge({
  "project_id": "payment-service",
  "query": "retry and idempotency rules"
})

AFTER IMPLEMENTING & TESTING

Save a fact with its evidence.

Review what was actually verified. Save the decision under the right project with a stable external ID, so a repeated write can be reconciled.

RUN IT YOURSELF

From checkout
to first context.

Start with Docker Compose, check readiness and import the canonical skills. Then create a project and connect each agent with its own credential.

Docker + Compose v2Python 3.12+OpenSSL

Run these commands from your checkout. Initial dependency and embedding-model downloads need network access. Allow several gigabytes of RAM for the complete stack.

Full setup, credentials & troubleshooting ↗
01 / START THE PLATFORM
./scripts/generate-dev-secrets.sh
if [ ! -x .venv/bin/python ]; then
  python3.12 -m venv .venv
fi
./scripts/prepare-docker-wheels.sh
docker compose config --quiet
docker compose up -d --build --wait
curl --fail http://127.0.0.1:8000/health/ready
make import-skills

Next: create your project, issue scoped credentials, and verify a handoff.
