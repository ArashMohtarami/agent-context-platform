# Packing tariff

Record: parcel-pack
Revision: 1
Status: active
Source: fictional project operations handbook

A package is charged by the larger of physical grams and volumetric grams. Volumetric grams are ceil(length_mm * width_mm * height_mm / 5000). The tariff is 175 cents for each started 500 grams. Dimensions and physical weight must be positive integers; booleans are not weights. Quotes never change stock.
