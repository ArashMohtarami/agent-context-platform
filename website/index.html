THE KNOWLEDGE LAYER

Conversations end.
Good decisions should stay.

Agents do the reasoning and implementation. The platform stores the facts, retrieves relevant context and preserves where it came from.

A clear path from client to context.

Compatible clients use a thin MCP server. Local Codex can connect over stdio; remote clients use Streamable HTTP. The gateway checks organization, verified sponsorship and coupled action/resource grants.

FastAPI services talk to MongoDB. MongoDB coordinates lexical and vector search through its private mongot service. A local embedding model supplies the vectors.

Understand the architecture ↗

The console overlay serves one exact HTTPS origin and removes API host ports. MongoDB and search remain private.

MEASURED, WITH LIMITS

No recall advantage claimed.

On one fictional 60-query corpus, hybrid and permitted Markdown both retrieve all 32 held-out supporting records in the top five. Hybrid returns unsupported material on 8/8 no-answer queries, versus Markdown 7/8. Zero forbidden returns across 723 attempts. Coding benefit and repeat use are unmeasured.
