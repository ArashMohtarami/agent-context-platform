# Waitlist promotion

Record: studio-waitlist
Revision: 1
Status: active
Source: fictional project operations handbook

Promote waiting groups in joined_at then request_id order. A group may be promoted only when its full size fits the currently free seats. An oversized group remains waiting and does not block later groups that fit. Each promoted request becomes a booking once; repeat promotion does not duplicate it. Keep the original waitlist order in stored history.
